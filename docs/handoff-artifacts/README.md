# Handoff artifacts

Files created during the 2026-10-15 working session that are not part of the website itself, kept here so the work can
be continued from the repository alone. The narrative (what was done, decisions, open items) is in `/HANDOFF.md`.

| Folder | What it is |
|---|---|
| `diana-verification/` | The reply to a prospective creator who asked for company due diligence before sharing her passport, and its two attachments: the plain-text reply (the version to send), the Data Protection and Passport Handling Statement (PDF, 2 pages) and a confirmation-letter **template** for Pace Gallery to put on its own letterhead. `build-documents.mjs` rebuilds both PDFs. Contains personal and company details: committed on purpose with the owner's approval (the repository is public). |
| `creators-email/` | The standalone "Plan your trip" HTML email for Pace Gallery creators (Kylie Manning: The Mudlarkers) and its builder. Reconstructed on 2026-11-08 (see the note at the top of the builder). |
| `qa-scripts/` | Playwright walkthrough scripts with mocked Supabase (see its README). |

- Third-party documents the owner uploaded (the Arts Abroad travel authorisation PDFs, an invoice, photos). Ask the owner to re-upload if needed.
